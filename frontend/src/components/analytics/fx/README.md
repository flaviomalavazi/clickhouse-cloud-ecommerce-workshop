# Analytics effects

Visual effects used only by `/demo/analytics`.

Adapted from third-party sources. Each file names its origin in its header:

- **Magic UI** (https://magicui.design, MIT, Copyright (c) Magic UI):
  `BorderBeam`, `AnimatedBeam`, `MagicCard`, `Marquee`, `DotPattern`, `BlurFade`.
  Rewritten from Tailwind v4 to this project's Tailwind v3 and inline styles,
  and trimmed to the props this page uses.
- **React Bits** (https://reactbits.dev, MIT + Commons Clause, Copyright (c) David Haz):
  `Aurora`. The Commons Clause permits use as part of an application or website and
  forbids selling the component itself; this demo only renders it.
